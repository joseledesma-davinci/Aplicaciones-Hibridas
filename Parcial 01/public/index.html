🐾 API REST - Sistema de Adopción de Mascotas

Bienvenido a la API de gestión y adopción de mascotas. Esta plataforma permite consultar animales disponibles, filtrar por especie o tamaño, buscar por nombre y gestionar refugios.

Endpoints Principales

  • GET /api/mascotas - Listar todas las mascotas (soporta filtros y búsqueda)
  • GET /api/usuarios - Listar todos los usuarios
  • GET /api/refugios - Listar refugios registrados
  • POST /api/mascotas - Crear mascota
  • POST /api/usuarios/ - Registrar nuevo usuario
  • POST /api/refugios/ - Registrar nuevo refugio
  • PUT /api/mascotas/:id - Actualizar mascota
  • PUT /api/usuarios/:id - Actualizar usuario
  • PUT /api/refugios/:id - Actualizar refugio
  • DELETE /api/mascotas/:id - Eliminar mascota
  • DELETE /api/usuarios/:id - Eliminar usuario
  • DELETE /api/refugios/:id - Eliminar refugio
