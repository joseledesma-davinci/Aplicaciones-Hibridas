🐾 API REST - Sistema de Adopción de Mascotas

Bienvenido a la API de gestión y adopción de mascotas. Esta plataforma permite consultar animales disponibles, filtrar por especie o tamaño, buscar por nombre y gestionar refugios.

Endpoints Principales

  • GET /api/mascotas - Listar todas las mascotas (soporta filtros y búsqueda)
  • GET /api/mascotas?nombre=luna - Búsqueda por nombre
  • GET /api/mascotas?especie=perro&tamano=mediano - Filtrado por especie y tamaño
  • GET /api/refugios - Listar refugios registrados
  • POST /api/auth/registro - Registrar nuevo usuario
  • POST /api/auth/login - Iniciar sesión y obtener JWT
  • POST /api/mascotas - Crear mascota (Requiere Bearer Token)
  • PUT /api/mascotas/:id - Actualizar mascota (Requiere Bearer Token)
  • DELETE /api/mascotas/:id - Eliminar mascota (Requiere Bearer Token)
